# Jhonny Dajay - Portfolio Website

A professional portfolio website showcasing customer service expertise and professional experience for job hunting purposes.

## Files Included

- **index.html** - Main website structure with all sections
- **styles.css** - Professional styling with responsive design
- **script.js** - Smooth scrolling and animation effects
- **README.md** - This file

## Features

✨ **Responsive Design** - Fully responsive on desktop, tablet, and mobile devices
🎨 **Modern Styling** - Professional color scheme and clean layout
📱 **Mobile Optimized** - Easy to navigate on all screen sizes
⚡ **Smooth Animations** - Scroll animations and transitions
🔗 **Easy Navigation** - Sticky navigation menu for quick access to sections
📧 **Contact Information** - Direct links to email and phone

## Sections

1. **Hero Section** - Eye-catching introduction with call-to-action buttons
2. **About** - Professional summary of experience and expertise
3. **Skills** - Organized by categories (Customer Support, Technical, Performance Metrics)
4. **Experience** - Detailed work history with key achievements
5. **Education** - Academic background
6. **Contact** - Multiple ways to get in touch

## How to Use

1. Open `index.html` in any web browser
2. The website will load with a professional layout
3. Use the navigation menu to jump between sections
4. Click "Get in Touch" to see contact information
5. The site is fully responsive - works great on phones too!

## Customization Tips

### Change Colors
Edit the color variables in `styles.css` (lines 8-16):
```css
--primary-color: #2c3e50;      /* Main dark blue */
--secondary-color: #3498db;    /* Light blue accent */
--accent-color: #e74c3c;       /* Red for buttons */
```

### Update Content
Edit the HTML in `index.html` to update:
- Contact information
- Professional experience details
- Skills and achievements
- Education details

### Add Social Media
Add social media links in the contact section by modifying the contact items.
